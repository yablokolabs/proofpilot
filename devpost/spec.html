ProofPilot AI: Technical Spec

One Next.js project. Three pipeline stages. Plain code checks the model's work between the stages.

Architecture and data flow

One check, step by step

Limits (src/lib/limits.ts). Empty text or text above 3,000 characters gives HTTP 400. No truncation. PRD: Text Input.
Claim Extractor (src/lib/extract.ts). One model call with a Zod schema. Each claim has a quote, a statement, and a search query. PRD: Claim Extraction.
Span Locator (src/lib/spans.ts). Code finds each quote in the text by exact match. A quote that is not found, or that overlaps, is counted as not assessed. Maximum 8 claims. Event: claims. PRD: Inline Claim Highlighting.
Evidence Retriever (src/lib/retrieve.ts). One Tavily search per claim: URL, title, content. PRD: Evidence Retrieval and Sources.
Claim Judge (src/lib/judge.ts). One model call per claim, 4 in parallel. Only the supplied sources are evidence. PRD: Claim Classification.
Citation Validator (src/lib/citations.ts). The URL must be a retrieved source. The excerpt must be a substring of the retrieved content. Supported or Contradicted with no valid citation becomes Unverified. Event: verdict.
Summary Logic (src/lib/summary.ts). Four counts and one status: review, all-supported, or no-claims. Event: done. PRD: Publication Readiness Summary.

Details

Stack
  • TypeScript, Node 22, pnpm
  • Next.js App Router, Tailwind CSS
  • Nebius Token Factory through the openai package, strict JSON schema with Zod, default model deepseek-ai/DeepSeek-V4-Pro (provisional)
  • Tavily JavaScript SDK
  • Vitest
How to run it
  • .env with NEBIUS_API_KEY and TAVILY_API_KEY
  • pnpm install, pnpm dev, open http://localhost:3000
  • pnpm test for unit tests
  • pnpm check:live "<text>" for the real pipeline
Failure modes
  • Missing key: clear error, text stays in the box
  • One claim fails: that claim is Unverified with the reason
  • Extraction fails: analysis error and retry
  • Quote not in text: not highlighted, counted as not assessed
  • Excerpt not in source: citation dropped
  • Stream stops early: error, no final status
Open issues
  • Model selection for the judge step: decided with real runs.
  • Keys: supplied by the learner, in the local .env file.
  • Agent readings to confirm: progressive results, local only.
  • The red highlight in the demo cannot be guaranteed. It is checked with real runs.
